# World Communication Document Management System

## Project

Production-ready Document Management System for World Communication.

## Purpose

Centralize customers, vendors/OEMs, products, purchase orders,
proforma invoices, tax invoices, attachments, document history,
reports, user permissions and backups.

## Architecture

- Development: MacBook
- Production Server: Ubuntu
- Backend: Python / FastAPI
- Database: PostgreSQL
- Frontend: Web application
- PDF: ReportLab
- Excel: openpyxl
- Remote Access: Secure VPN / private network
